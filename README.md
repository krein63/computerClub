# Top Game — Assignment 3

Учебный сайт компьютерного клуба Top Game: семь существующих страниц переведены на Bootstrap 5.3.8. Тема и содержимое сохранены; сетка, навигация, адаптивность, кнопки и отступы используют Bootstrap.

## Запуск

Откройте `index.html` в браузере. На macOS из папки проекта:

```sh
open index.html
```

Сервер, установка зависимостей и хостинг не нужны. Bootstrap 5.3.8 CSS загружается с CDN jsDelivr, поэтому для оформления нужен интернет. В проекте нет JavaScript, скриптов, файлов `.js` и обработчиков событий. Серверной обработки форм нет: кнопки `type="submit"` в `booking.html` и `games.html` имеют `disabled`; поля и сброс формы доступны.

## Адаптивность

- Карточки зон на главной, тарифов и компьютеров: `col-12 col-md-6 col-lg-4` — одна колонка при 375 px, две от `md` (768 px), три от `lg` (992 px).
- Преимущества на главной: `col-12 col-sm-6 col-lg-3` — одна колонка, две от 576 px, четыре от 992 px. Текст и фото первого блока стоят рядом от 992 px благодаря `col-lg-6`.
- `navbar-expand-xl` задаёт раскладку меню на широком экране. При ширине меньше 1200 px HTML checkbox вместе с CSS скрывает и показывает меню без JavaScript. Этот переключатель добавляет собственное CSS-поведение, потому что пользователь попросил убрать скрипты.
- `text-center text-md-start` выравнивает главный заголовок по центру на телефоне и по левому краю от 768 px. `d-none d-md-block` показывает подпись фотографии от 768 px.
- `container` ограничивает ширину основного текста; `container-fluid` использует ширину шапки для семи ссылок. `row` внутри колонки формы в `booking.html` показывает вложенную сетку; интервалы задают `g-3` и `g-4`.

## Проверка и сдача

Перед сдачей запустите Nu HTML Checker на текущем состоянии проекта; предыдущая проверка относится к версии до CSS-переключателя. Команда для локального Nu HTML Checker:

```sh
java -jar /path/to/vnu.jar --format json *.html
```

После изменения выполнены статические проверки всех семи страниц: скрипты, inline event handlers, JS-файлы и повреждённые локальные ссылки не найдены. Аудитор также проверил структуру CSS-переключателя. Полную проверку меню в браузере на 375, 768 и 1440 px нужно повторить после этого изменения. Четыре снимка находятся в `screenshots/`.

Не подделывайте историю коммитов и их даты. Задание требует минимум четыре реальных коммита каждого участника за три разных дня; при работе в одиночку — шесть. Изменения, созданные AI, сами по себе не заменяют личный вклад студента.

Автоматическую миграцию выполнил AI, а агенты помогают с проверкой. Это не соответствует запрету AI policy задания на перестройку страниц искусственным интеллектом. Подробности и точный запрос записаны в `AI-log.txt`; эту версию нельзя представлять как полностью самостоятельную работу участников.
