# TOP GAME

Учебный сайт компьютерного клуба в Астане. В проекте семь страниц, каталог из 26 игр, девять тарифов, схема 20 ПК и меню еды.

## Запуск

Откройте `index.html` или запустите из папки проекта `python3 -m http.server 8000` и перейдите на `http://localhost:8000/index.html`. Bootstrap и jQuery 3.7.1 хранятся в проекте. Интернет нужен для перехода на внешние сайты.

## Что можно показать на защите

1. Откройте «Цены» и выберите пакет на пять часов. В бронировании укажите будущую дату и время, выберите пять ПК в MAIN или DUO. Стоимость составит 22 500 ₸.
2. Нажмите «Сохранить и перейти к еде». Добавьте воду, откройте корзину и перейдите к общему итогу. В списке заявок выберите визит или пункт «Только еда». Прошедшие визиты остаются в истории.
3. Покажите ночной пакет на пять часов. Начало в 02:00 укладывается в ночной интервал 23:00–07:00 по Астане, начало в 02:01 отклоняется.
4. Откройте каталог игр в двух вкладках. Найдите игру, отметьте сердечком и проверьте обновление избранного во второй вкладке.
5. На странице правил откройте чек-лист, отметьте пункт, обновите страницу и сбросьте отметки.

Заявки, корзина и избранное хранятся в браузере. Заявку на ПК нужно подтвердить звонком в клуб. Позиции из корзины можно назвать администратору и оплатить в клубе. Общей карты занятости между устройствами и онлайн-оплаты в проекте нет.

## Устройство проекта

| Файл | Что делает |
| --- | --- |
| `js/data.js` | Хранит тарифы, позиции меню и игровые места |
| `js/logic.js` | Считает стоимость и проверяет интервалы, форматы и сохранённые заявки |
| `js/prices.js` | Обычный JavaScript. Строит таблицу тарифов и ссылки на бронирование |
| `js/booking.js`, `js/booking-tabs.js` | Проверяют форму и занятость, сохраняют заявки, переключают шаги и обновляют итог |
| `js/food.js` | Фильтрует меню, меняет количество позиций и открывает корзину |
| `js/games.js` | Строит каталог, фильтрует игры и синхронизирует избранное |
| `js/rules.js` | Сохраняет черновик чек-листа на два часа в пределах одной вкладки |
| `js/main.js`, `css/base.css` | Подключают общие элементы интерфейса, тему и анимации |

Для актуальных проверок выполните `node checks/endterm.cjs` с установленными Node.js и Playwright. Переменные `PLAYWRIGHT_MODULE` и `CHROMIUM_PATH` позволяют указать путь к уже установленным инструментам. Остальные отчёты в `checks/` относятся к предыдущим версиям.

HTML и CSS менялись после тега `midterm`. Сверьте правила эндтерма с оригиналом задания.
