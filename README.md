# TOP GAME — версия для подготовки к Endterm

Обновлено 8 ноября 2026 года по `endterm_project (1).docx`. Сохранён тот же проект: семь страниц, компьютерный клуб, исходное оформление и данные. Git пользователь ведёт самостоятельно. Цены и контакты приняты как правильные по его указанию; значения не менялись.

## Запуск

Распакуйте архив. Откройте папку через Live Server в редакторе или запустите `python -m http.server 8000` из этой папки и перейдите на `http://localhost:8000/index.html`. Сборка не нужна. Для jQuery 3.7.1 Full нужен интернет: библиотека подключена с официального CDN с проверкой integrity. Bootstrap используется как CSS.

Это демонстрация для одного посетителя: бронь, заказ еды, запрос игры и отзыв можно заполнить, проверить и завершить с результатом в браузере. Сайт не создаёт реальное бронирование, оплату или установку игры в клубе. Контакты из заявок не записываются в localStorage; введённые отзывы сохраняют имя и текст.

## Где обычный JavaScript, где jQuery

| Файл | Задача и что показывать на защите |
| --- | --- |
| `js/data.js` | Обычный JS: реальные данные проекта в массивах и объектах — 6 тарифов, 20 ПК, 8 товаров. Единый источник цен |
| `js/logic.js` | Общие чистые JS-функции без DOM: расчёт стоимости визита/корзины, поиск и проверка целого количества |
| `js/prices.js` | Обычный JS: `createElement`, `textContent`, циклы, `replaceChildren`, `addEventListener`, `classList`. Каталог, таблица, калькулятор, подбор пакетов и их события полностью принадлежат этому файлу |
| `js/main.js` | jQuery: тема, навигация и общие помощники для jQuery-разделов; цепочки, ошибки и fade-уведомления |
| `js/booking.js` | jQuery: выбор ПК, проверка формы, расчёт, сохранение и отмена локальной брони; делегированные кнопки |
| `js/food.js` | jQuery: меню, фильтры, корзина, итог и завершение локального заказа |
| `js/games.js` | jQuery: каталог, избранное, поиск, запрос игры и его результат |
| `js/rules.js` | jQuery: поиск помощи, инструкции со slide-эффектами, проверка перед уходом и черновик |
| `js/computers.js`, `js/about.js` | jQuery: фильтры/сравнение оборудования и локальные отзывы |
| `js/old-js-version.js` | Только историческое сравнение трёх файлов. К сайту не подключён и не считается действующей JS-частью |

В `prices.js` нет вызовов jQuery и помощников `TopGame.el/setError/notify`, работающих через jQuery. `TopGameData` и `TopGameLogic` не зависят от библиотеки. Общая навигация и корзина остаются отдельными jQuery-функциями, в том числе на странице цен. Отдельная проверка запускает тарифы без этих скриптов и без jQuery.

## Карта требований

- Данные и циклы: `data.js`, построение карточек/строк таблицы/вариантов в `prices.js`. Новая разметка подбора существует только в коде. Старые карточки frozen HTML заменяются при запуске; новые элементы вручную в HTML не добавлялись.
- Функции с параметрами и возвратом: например, `calculate(tariffId, rawPlayers, rawHours)` вызывается при редактировании и отправке, `matchingPackages(visit)` — при выводе списка и повторной проверке выбранного предложения. `element`, `field`, `money`, `setError`, `feedback` используются многократно.
- Условия и рассчитанные числа: фиксированный пакет оплачивается целиком; почасовой умножается на часы; сумма группы и цена на игрока вычисляются. В подборе учитываются 15 мест MAIN/DUO и 5 PRIVATE. Ночной пакет предлагается только для ночного сеанса. Это сравнение цен, не проверка реальной свободной вместимости: места проверяются далее в бронировании.
- События: `click`, `input`, `change`, `submit`, `reset`, `keydown`, `hashchange`, `storage`. Все обработчики назначены в коде. Нативный делегированный обработчик подбора использует `event.target.closest()`, формы — `preventDefault()`. В jQuery есть делегирование мест, избранного и инструкций.
- Основная форма: имя, email, телефон, дата и будущее время, целое число игроков/часов, тариф, зона, выбранные ПК, пересечения броней, комментарий и согласие. Строки обрезаются через `trim`; ошибки рядом с полями; исправление сразу снимает ошибку; подтверждение возможно только после проверки. Успешная бронь очищает форму и оставляет результат с отменой.
- jQuery: ID/класс/тег/атрибут/фильтр; `closest/find/siblings`, `$(this)`, цепочки от трёх методов; `fadeIn/fadeOut` для сообщений и `slideDown/slideUp` для инструкций с возвратом фокуса.
- Состояния: `hidden` — скрытие блоков/выполненных пунктов, `active` — текущая навигация/выбранный пакет, `error` — ошибки, `success` — успешные результаты. Классы включаются и выключаются кодом.
- Внешний вид: новые CSS-правила и ручная HTML-разметка не добавлялись. HTML/CSS совпадают с переданным исходным архивом, кроме ранее добавленного подключения CDN. Сравнение с настоящим тегом `midterm` нужно выполнить в вашем репозитории.

## Как показать новые функции

1. «Цены»: 5 игроков, 5 часов, бюджет 28 000 ₸, MAIN/DUO, дневной сеанс. Появится пакет 5 часов за 27 000 ₸ для команды. Уменьшите бюджет до 26 999 ₸ — появится понятное сообщение. Верните бюджет, выберите пакет и перейдите к бронированию: 5 игроков и пакет перенесутся.
2. Покажите дробное число игроков, лишние часы и отрицательный бюджет: ошибка возле соответствующего поля. Исправьте — она исчезнет. Для PRIVATE нельзя подобрать больше 5 мест.
3. «Игры»: добавьте Dota 2 в избранное, обновите страницу, выберите «Только избранные», затем удалите игру из списка. Поиск и выбор для запроса продолжают работать.
4. «Правила»: отметьте пункт, обновите страницу и увидите восстановление. Покажите только невыполненные, завершите все пункты или начните заново. Проверка не выходит из аккаунтов за посетителя.
5. Покажите ошибки пустой брони, исправьте контакты, выберите будущий визит и ПК, завершите локальную заявку и отмените её. Откройте инструкции в правилах и объясните slide-эффект и callback.

## Проверки

`checks/endterm.cjs` проверяет новые функции, граничные значения бюджета, перенос параметров, независимость обычного JS, избранное, запрет хранения, восстановление/истечение черновика и навигацию. Результат — `checks/endterm.json`.

`checks/assignment6-jquery.cjs` проверяет 37 прежних сценариев: семь страниц на трёх ширинах, формы, делегирование, бронь между зонами/вкладками, корзину, расчёты, оборудование, отзывы, запрос игры, эффекты и мобильное меню. Отчёт актуального запуска — `checks/endterm-regression.json`. Дополнительные проверки ссылок, разметки и W3C — в `checks/endterm-site.json`, `checks/endterm-w3c.json`.

Для повторного запуска нужен установленный вне сайта Playwright и Chrome. Задайте `PLAYWRIGHT_MODULE` и `CHROMIUM_PATH` при необходимости. Запуск новых проверок: `node checks/endterm.cjs`. Можно задать `JQUERY_TEST_FILE` с официальным полным файлом jQuery 3.7.1: проверка сверит SHA-256. Это только способ тестирования; сайт продолжает загружать CDN. В текущих браузерных проверках использовалась такая проверенная копия; доступность живого CDN ими не подтверждается.

Старые отчёты относятся к своим версиям. Реальный quality pass другим участником или на другом устройстве оформляется в `quality-pass.md`; автоматические проверки не заменяют его.
