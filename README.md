# Top Game — Midterm

Учебный сайт компьютерного клуба Top Game в Астане: семь страниц, единая навигация, Bootstrap 5.3.8, готовая разметка форм и состояний для следующего этапа с JavaScript. Подготовлен по `midterm_project.docx` на основе того же репозитория и темы.

**Текущий этап — HTML и CSS.** JavaScript отсутствует. Навигация, мобильное меню, ввод и сброс полей работают средствами браузера. Кнопки формирования карточек подготовлены, но пока не обрабатывают данные. Это разрешено разделом задания «No JavaScript yet». Сайт не отправляет заявки, не резервирует реальные места, не принимает оплату и не обещает ответ сотрудника. Формы предназначены для личного плана одного посетителя.

Техническая подготовка не означает выполнение всех условий сдачи: подтверждение материалов, личный взаимный просмотр, история каждого участника и соблюдение AI policy отдельно описаны в `QUALITY_PASS.md`.

## Запуск

Откройте `index.html` в браузере. На macOS из каталога проекта:

```sh
open index.html
```

Установка пакетов и интернет для оформления не нужны: Bootstrap CSS и изображения находятся в проекте. Внешняя карта и телефонные ссылки требуют соответствующего приложения или подключения.

Для проверки через локальный сервер при установленном Python:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

| Файл | Содержание | Окончание маршрута |

## Три маршрута посетителя

### 1 Найти адрес и часы работы

**Старт:** `index.html`.

1. Открыть «О клубе» в общей навигации.
2. Нажать «Как добраться» в первом блоке.
3. В разделе `about.html#contacts` прочитать адрес, телефон и режим 24/7.
4. При необходимости открыть «Открыть адрес в 2GIS».

**Конец:** адрес и часы видны на сайте; есть ссылка на реальную карточку клуба. Для завершения информационного маршрута ответ сотрудника не нужен.

### 2 Сравнить зоны и подготовить визит

**Старт:** `computers.html`.

1. Сравнить Main, Duo’s и Private по процессору, видеокарте и монитору.
2. Через общую навигацию перейти в «Цены» и сравнить тарифы.
3. Нажать «К плану визита» либо вернуться к компьютерам и нажать «К выбору зоны в плане».
4. На `booking.html` заполнить имя/ник, дату, время, число игроков, тариф, длительность и выбрать зону; прочитать правила и отметить ознакомление.
5. Нажать «Сформировать план визита» и проверить, где размещены карточка, сообщения и ориентир цены. «Очистить поля» действительно сбрасывает форму.

**Конец midterm:** посетитель самостоятельно заполняет план; место для результата и все поля карточки видны. Кнопка пока не создаёт карточку — это статический этап, а не подтверждённая бронь. Ссылки на зоны переводят к полю, но не выбирают радиокнопку автоматически. Ночной пакет доступен как тариф; длительность задаётся как пожелание посетителя, не как подтверждённые часы пакета.

### 3 Выбрать игру и подготовиться к сессии

**Старт:** `index.html`, блок «Игры».

1. Перейти в `games.html`, прочитать карточку CS2 или Dota 2.
2. Нажать «Запланировать CS2» или «Запланировать Dota 2»; ссылка ведёт к форме личного плана.
3. Ввести название игры, выбрать цель сессии, при желании добавить заметку.
4. Нажать «Добавить в план» и увидеть предусмотренную область «Мой план». До JavaScript данные остаются в полях; сброс работает.
5. Перейти по «Прочитать правила» к `rules.html#account-safety` и прочитать памятку выхода из аккаунта.

**Конец:** посетитель выбирает цель личной сессии и узнаёт правила безопасности. Запрос установки сотруднику, командное согласование и обещание ответа отсутствуют. Карточки игр не подтверждают установленную версию на конкретном ПК.

## Разметка для JavaScript

Полная карта интерфейса и правил поведения — в `JS_HOOKS.md`.

- Каждая форма, поле и кнопка имеют стабильный `id` в английском kebab-case.
- Подготовлены результаты, сообщения ошибки и успеха, пустые состояния, выходные поля карточек.
- В `css/base.css` заранее определены `.is-hidden`, `.is-active`, `.is-selected`, `.is-error`, `.is-success`, `.field-error`, `.state-message`.
- Валидационные атрибуты и подписи уже стоят в HTML. Динамические проверки даты и совместимости тарифа относятся к следующему этапу.
- В библиотеке скрытая отключённая submit-кнопка предотвращает случайную GET-отправку при Enter. Рабочие действия имеют `type="button"`; очистка — `type="reset"`.
- Переключатель меню использует checkbox и CSS. Обработчиков событий, `<script>`, Bootstrap JS и файлов JavaScript в сдаваемом проекте нет.

## Bootstrap и адаптивность

`css/vendor/bootstrap.min.css` — Bootstrap 5.3.8, лицензия рядом. `css/base.css` — небольшой слой фирменных цветов, состояний и CSS-переключателя меню; сетка не переписана вручную.

- Зоны: `col-12 col-md-6 col-lg-4`; тарифы: `col-12 col-md-6 col-xl-3`.
- Форма и результат стоят рядом от `lg`; на телефоне идут последовательно.
- Меню раскрывается при ширине меньше 1200 px. Оно доступно с клавиатуры: фокус на checkbox, переключение пробелом.
- В таблице тарифов на телефоне остаются тариф и цена; подробности каждого тарифа есть в карточках выше. От `md` видны все четыре колонки.
- Общие `container`, `row`, `g-*`, `card`, `btn`, `form-control`, `form-select`, `table` обеспечивают раскладку. Нет маскировки переполнения страницы через `overflow-x:hidden`.

