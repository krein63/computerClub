# TOP GAME — Assignments 4–5

Сайт компьютерного клуба с картой 20 ПК, бронированием, заказом еды, каталогом игр, тарифами и отзывами. Формы отправляют заявки в хранилище текущего браузера. Серверная обработка, оплата и синхронизация между устройствами не подключены — этот вариант выбран пользователем.

## Запуск

Все ресурсы локальные, сборка и установка библиотек для сайта не нужны:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Можно открыть `index.html` напрямую, но сохранение между страницами стабильнее через статический сервер. Для ссылок на внешние сайты нужен интернет.

### Бронирование

Заполните контакты, будущую дату и время, выберите тариф и свободные ПК. MAIN — 10 мест, DUO — 5, PRIVATE — 5. Можно выбрать компьютеры из нескольких зон: нажатия на карте обновляют количество игроков; изменение предпочтительной зоны не сбрасывает выбор. Отдельного ограничения DUO на двух игроков нет.

«Отправить заявку» проверяет поля и сохраняет бронь. Один ПК нельзя занять дважды на пересекающееся время; соседние интервалы допускаются. Занятость отражает сохранённые заявки в этом браузере, искусственно занятых мест нет. Повторное нажатие не дублирует принятую бронь. «Отменить бронь» освобождает её места. Старая история заявок поддерживается.

### Еда и запрос игры

Соберите корзину, выберите получение, заполните контакты и подтвердите состав. «Отправить заказ» сохраняет позиции, сумму и получение в браузере, показывает итог и очищает корзину. Пустую корзину отправить нельзя. Количество товара — от 1 до 20; уменьшение до нуля удаляет позицию.

Запрос игры проверяет контакты, дату, игроков, название/жанр, согласие и сочетание командной игры с числом участников. «Отправить запрос» сохраняет результат в браузере. Установка игры не выполняется. Отзывы также сохраняются локально, текст проверяется на 20–1000 символов.

Карточки, таблица, калькулятор и бронирование используют один массив `js/data.js`. Фиксированный пакет умножается на количество ПК; почасовой — ещё и на часы. Пакеты и периоды — настройки текущего проекта, а не независимо подтверждённый прайс клуба. Новые варианты добавлены по запросу пользователя 12 октября. Источники и статус данных: [content-sources.md](content-sources.md).

## JavaScript и хранение

`data.js` — данные; `logic.js` — расчёты и фильтр; `main.js` — общие DOM-функции, темы, ошибки, хранение и навигация. `food.js` — меню и корзина; остальные файлы отвечают за свои страницы. Обычные массивы, объекты, циклы и функции, без JS-фреймворков. Bootstrap используется как CSS. Памятка для защиты: [DEFENSE_GUIDE.md](DEFENSE_GUIDE.md).

`localStorage` хранит корзину, интервалы/номера ПК, заказы еды, запросы игр и отзывы. Контакты заявки на бронь/еду/игру не сохраняются. Отзыв содержит введённое имя и текст. При недоступном хранилище интерфейс показывает временный режим. Новые номера заявок начинаются с `TG`; старые номера отображаются без прежнего префикса.

HTML всех семи страниц отличается от `midterm` только подключениями скриптов через `defer`. CSS совпадает с `midterm`. Новые разделы создаются через DOM; тёмное оформление, контраст таблиц и карточек задаётся готовыми классами Bootstrap. Изначальные 45 ПК заменяются через DOM на 20.
