# Как объяснить JavaScript на защите

Сайт работает без сборки и дополнительных JS-библиотек. Bootstrap здесь используется только как CSS. Скрипты подключены через `defer`: сначала браузер читает HTML, затем выполняет JS.

1. `data.js` — массивы товаров, тарифов и 20 ПК. У товара есть название, цена, категория и фотография.
2. `logic.js` — простые расчёты. `findProduct` ищет товар через `find`, `filterMenu` отбирает товары через `filter`, `cartTotals` обычным циклом складывает цену × количество.
3. `main.js` — общие функции: создание элемента, формат цены, сообщения об ошибках и сохранение в браузере. `el` использует `createElement` и `textContent`, поэтому введённый текст не становится HTML. Тёмная тема использует готовые классы Bootstrap.
4. `food.js` — массив `cart` хранит id товара и количество. При добавлении количество увеличивается, при удалении строка убирается. Затем корзина рисуется заново, итог пересчитывается и массив сохраняется в `localStorage`.
5. `booking.js` — массив выбранных номеров ПК. Нажатие добавляет или удаляет номер. Занятость проверяется по пересечению времени: начало новой заявки раньше конца старой, а конец новой позже начала старой. При совпадении границ заявки не пересекаются.
6. Остальные файлы отвечают только за свою страницу: фильтры тарифов/игр, сравнение зон и локальные отзывы.

`const` используется для неизменяемой переменной, `let` — когда значение меняется. `addEventListener` вызывает функцию после действия пользователя. `if` проверяет условие, `for` перебирает массив, `includes` проверяет наличие номера, `filter` создаёт массив подходящих элементов.

`const { el, money } = window.TopGame` получает общие функции из объекта. `(...items)` в аргументах разворачивает массив элементов. `(() => { ... })()` выполняет код файла в отдельной области видимости, чтобы переменные страниц не конфликтовали. Это стандартный JavaScript, без фреймворка.

Перед сохранением формы проверяются контакты, дата, количество участников и выбранные места. Бронирование и заказ демонстрационные: сервер и оплата отсутствуют.

Объём JS обусловлен требованием создавать новые элементы через DOM, сохраняя исходный HTML/CSS. Удаление этой части нарушило бы документ. Код упрощён по структурам данных и расчётам; количество строк не скрывается сжатием. Для защиты нужно самостоятельно разобраться в функциях и учитывать запрет задания на AI-код, раскрытый в `AI-log.txt`.
