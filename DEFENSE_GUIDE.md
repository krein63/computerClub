# Как объяснить проект на защите

В проекте есть обычный JavaScript и jQuery. jQuery — библиотека, написанная на JavaScript; она помогает короче находить элементы, обрабатывать действия и показывать анимацию.

## Обычный JavaScript — «Цены»

Откройте `js/data.js`: в массиве `tariffs` лежат объекты тарифов. У каждого есть свойства `id`, `name`, `price`, `duration`, `hourly`. `hourly: true` означает оплату за каждый час; `false` — оплату фиксированного пакета.

Откройте `js/prices.js`:

- `document.createElement()` создаёт элемент. `textContent` записывает текст. `append()` вставляет элементы на страницу.
- Цикл `for...of` берёт каждый тариф и создаёт строки таблицы/карточки. В HTML новые карточки подбора вручную не записаны.
- Функция `calculate(tariffId, rawPlayers, rawHours)` получает три значения, проверяет их и возвращает объект с суммой и ошибками. Она вызывается при изменении полей и при отправке формы.
- Почасовая стоимость: цена × часы × игроки. Фиксированный пакет: цена пакета × игроки. Например, 5 часов за 5 400 ₸ для 5 человек = 27 000 ₸.
- `matchingPackages(visit)` пропускает неподходящую зону, слишком короткие пакеты и варианты дороже бюджета. Ночной пакет участвует при выборе ночного сеанса. `.sort()` ставит меньшую сумму первой.
- `addEventListener('submit', ...)` слушает отправку. `event.preventDefault()` отменяет обычную отправку, чтобы проверить форму и показать результат на странице.
- Обработчик клика стоит на `#finder-results`. `event.target.closest('[data-choose-package]')` находит кнопку, даже если нажали на её вложенный элемент. Кнопки можно пересоздавать, обработчик на родителе продолжит работать.
- `classList.toggle('active', условие)` отмечает выбранный пакет. `aria-pressed` сообщает состояние кнопки вспомогательным программам.

Покажите 5 игроков, 5 часов, бюджет 28 000 ₸. Выберите предложенный пакет, перейдите к бронированию. Затем попробуйте нулевой бюджет и дробное число игроков и объясните сообщения.

## jQuery — «Игры»

Откройте `js/games.js`. `$(function () { ... })` ждёт готовности страницы. `$()` находит элемент, `.val()` читает поле, `.text()` выводит безопасный текст, `.on()` назначает обработчик.

Избранное хранит только идентификаторы игр. Например, `['dota2']`. Клик по кнопке добавляет ID в массив или удаляет его. `app.store.set()` записывает массив в localStorage. После обновления страницы список восстанавливается. Фильтр оставляет карточки, ID которых есть в массиве. Если список пуст, появляется сообщение. Если браузер запрещает хранение, избранное работает до перезагрузки и сайт сообщает об этом.

Обработчик `.on('click', '[data-favorite-game]', function () {...})` прикреплён к родителю карточек. В нём `$(this)` — кнопка, по которой нажали. Поэтому обработчик работает после поиска и перестроения списка.

Свойство `source: true` означает, что игра была упомянута на исходной странице. `false` означает добавленное предложение для каталога. Это не признак установленной игры.

## jQuery — «Правила»

Откройте `js/rules.js`. Поиск выбирает подходящие ситуации из массива. При выборе карточки `.closest('article')` находит её, а `.parent().siblings().find('article')` находит остальные карточки и снимает их выделение.

`.slideDown(220)` открывает инструкцию, `.slideUp(180)` закрывает. Числа — миллисекунды. Callback выполняется после анимации и возвращает фокус на кнопку. В `main.js` сообщения используют `.fadeIn()` и `.fadeOut()`.

В проверке перед уходом `.prop('checked')` читает текущее состояние галочки. Количество выполненных пунктов считается из выбранных значений. Завершить можно только после всех пунктов. Черновик хранится в sessionStorage этой вкладки до двух часов; это помогает после случайного обновления страницы. Это самостоятельная проверка: сайт не выходит из игровых аккаунтов за человека. Завершение и сброс удаляют черновик.

## Проверки формы и состояния

Основная форма — в `booking.js`. `trim()` убирает пробелы по краям строк. Проверяются контакты, дата/время, тариф, игроки, часы, зона, места и согласие. Ошибка выводится возле соответствующего поля. После исправления исчезает. Только правильные значения создают локальный результат.

`hidden` скрывает блок, `active` отмечает текущий пункт меню или пакет, `error` показывает ошибку, `success` — успешный результат. Все эти классы переключаются кодом. Их оформление уже существует в CSS.

Функция — отдельный вызываемый блок кода, например `calculate(...)`. Метод — функция, доступная как свойство объекта, например `array.filter(...)`, `element.append(...)`, `app.store.get(...)`. `true` и `false` — логические значения «да» и «нет», без кавычек.

## Что могут попросить изменить

1. Добавить поле и проверку: создать его в коде, прочитать значение, проверить условие и вывести ошибку рядом.
2. Изменить максимальное число часов: найти ограничение и понять, какие другие проверки используют тот же предел.
3. Добавить тариф: добавить объект в массив и показать обновлённые карточки, таблицу и расчёты.
4. Показать избранные игры или снять одну: объяснить `includes`, `filter`, обновление списка и хранение.
5. Изменить длительность эффекта или объяснить callback и делегирование.
6. Переписать короткое выражение: `$('#id').text('Текст')` → `document.querySelector('#id').textContent = 'Текст'`.
