# Проверки TOP GAME

Актуальный набор сценариев запускается командой `node checks/endterm.cjs`. Нужны Node.js и Playwright с Chromium. `PLAYWRIGHT_MODULE` задаёт путь к установленному Playwright, `CHROMIUM_PATH` — путь к браузеру.

Проверка открывает семь страниц на ширине 1440 и 390 px, проверяет тарифы, бронирование, ночное время, общий итог, прокрутку корзины, избранное и чек-лист правил. Браузер получает файлы проекта без внешних запросов.

Остальные сценарии и отчёты здесь сохранены для истории. Их селекторы, ожидаемые цены и отчёты о результатах относятся к прежним версиям.
