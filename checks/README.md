# Проверки Assignment 5

`assignment-5.json` — фактический отчёт браузерной проверки. `functional-review.md` и `design-review.md` — независимые отчёты агентов. Поле `sourceSha256` связывает проверку с точными файлами исходников; `baseline.head` указывает HEAD на момент начала запуска и может предшествовать коммиту материалов сдачи.

`browser-check.cjs` проверяет все семь страниц на 375, 768 и 1440 px, ресурсы/консоль/переполнение, HTML/CSS freeze и завершённые пользовательские сценарии. Тесты не подключаются к интерфейсу сайта.

Для повторного запуска проверки нужен Git checkout с тегом midterm, Node.js, установленный вне сайта пакет Playwright и браузер Chromium/Chrome. Это зависимости только инструмента проверки; сайт по-прежнему работает без установки библиотек.

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node checks/browser-check.cjs
```

Можно указать `CHROME_PATH` для другого исполняемого файла Chrome и `QA_OUTPUT` для папки результатов. На macOS по умолчанию используется установленный Google Chrome; на других системах — браузер, доступный Playwright. По умолчанию результаты нового запуска сохраняются в `checks/generated/`.
