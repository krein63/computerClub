# Проверки сайта

Актуальная версия — 8 ноября 2026. Скрипты в этой папке служат разработке и не подключаются к сайту.

- `endterm.cjs` / `endterm.json`: новые функции — подбор пакетов, границы бюджета, передача в бронирование, независимый обычный JS, избранное, запрет хранения, черновик проверки перед уходом и навигация.
- `endterm-regression.json`: свежий запуск 37 сценариев из `assignment6-jquery.cjs` против итоговых исходников.
- `endterm-site.json`: дополнительные проверки форм, внутренних ссылок, идентификаторов, отсутствия inline-обработчиков и сравнение HTML/CSS с переданным архивом.
- `endterm-w3c.json`: официальный W3C Nu, исходные HTML и начальные сгенерированные страницы без введённых пользователем данных. Это проверка синтаксиса разметки, не сертификат доступности всего сайта.

Запуск: `node checks/endterm.cjs` или `node checks/assignment6-jquery.cjs`. Нужны Node.js, внешний Playwright и Chrome. `PLAYWRIGHT_MODULE` задаёт путь к Playwright, `CHROMIUM_PATH` — к Chrome. Сайт не требует установки этих инструментов.

Тест endterm поддерживает `JQUERY_TEST_FILE` для официальных байтов jQuery 3.7.1 Full с обязательной проверкой SHA-256. Для текущих браузерных запусков использовалась проверенная локальная копия; это не проверяет доступность CDN через интернет. Сайт продолжает использовать CDN.

Старые отчёты сохраняются как история и относятся к своим контрольным суммам. `browser-check.cjs` из ранней версии ожидает настоящий Git checkout с тегом midterm; в этом архиве его нет. История Git оставлена пользователю. Автоматические проверки не заменяют личный quality pass каждого участника минимум за два дня до дедлайна.
