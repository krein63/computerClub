КАК ОБЪЯСНИТЬ JAVASCRIPT В ПРОЕКТЕ TOP GAME

Главная мысль
HTML задаёт содержимое страницы, CSS — внешний вид, JavaScript — действия.
Например: пользователь выбирает ПК, и итоговая цена меняется.

Зачем нужен каждый файл
• data.js хранит тарифы, меню и список 20 компьютеров.
• logic.js содержит общие расчёты и поиск данных.
• main.js даёт страницам общие функции: формат цены, ошибки и сохранение данных.
• prices.js фильтрует тарифы и считает примерную стоимость посещения.
• computers.js фильтрует игровые зоны и позволяет сравнить их.
• booking.js связывает три шага, общую корзину, форму и демонстрационную заявку.
• games.js ищет игры, проверяет форму и показывает итог запроса игры.
• rules.js ищет нужную инструкцию и считает отметки в проверке перед уходом.
• about.js проверяет отзывы, показывает их и сохраняет в браузере.
• food.js показывает меню и передаёт корзину еды общему заказу.

Как происходит действие
1. Пользователь нажимает кнопку или меняет поле.
2. Браузер создаёт событие: click, input, change или submit.
3. addEventListener вызывает функцию для этого события.
4. Функция читает значения, проверяет их и делает расчёт.
5. Функция меняет DOM — элементы страницы, которые видны в браузере.
Пример цепочки: выбор ПК → click → функция расчёта → новая цена на странице.

Основные слова
const — переменная, которой нельзя присвоить другое значение.
Поля объекта и элементы массива внутри const менять можно.
let — переменная, значение которой можно менять, например счётчик.
function — именованный набор действий, который можно вызвать несколько раз.
if — выполняет действие, только если условие верно.
for — повторяет действия; for...of перебирает элементы массива или списка.
getElementById — находит HTML-элемент по его id.
addEventListener — связывает событие с функцией.
textContent — читает или меняет текст элемента, не превращая его в HTML.
localStorage — хранит данные в этом браузере между открытиями страницы.
Для сохранения массива или объекта используют JSON.stringify, для чтения — JSON.parse.
DOM — представление HTML-страницы в виде элементов, доступных JavaScript.

Простой пример принципа расчёта
function calculatePrice(pricePerHour, hours, players) {
    const total = pricePerHour * hours * players;
    return total;
}

const result = calculatePrice(1200, 3, 2);

Что здесь происходит
• calculatePrice — имя функции.
• pricePerHour, hours и players — параметры, то есть входные данные.
• При вызове они получают значения 1200, 3 и 2.
• Знак * означает умножение: 1200 × 3 × 2 = 7200 тенге.
• total хранит итог, return возвращает его из функции.
• result получает число 7200; его можно показать через textContent.
В проекте дополнительно учитывается выбранный тариф и проверяется ввод.

Пять коротких вопросов и ответов
1. Зачем код разделён на файлы?
   Чтобы данные, общие функции и действия отдельных страниц было легче найти.
2. Что запускает действия на странице?
   События пользователя; обработчики подключены через addEventListener.
3. Зачем проверять поля формы?
   Чтобы показать понятную ошибку и не создать итог с неверными данными.
4. Почему корзина и отзывы остаются после обновления страницы?
   Они сохраняются в localStorage этого браузера.
5. Создаёт ли сайт настоящую бронь или заказ?
   Нет. Это демонстрация: данные не отправляются в клуб на сервер.
