О создании сайта

Как создавался сайт TOP GAME

Эта страница рассказывает о процессе разработки учебного сайта компьютерного клуба TOP GAME. Проект состоит из шести связанных HTML-страниц. На них представлена информация о клубе, игровых компьютерах, ценах и бронировании. Все страницы открываются локально в браузере и связаны относительными ссылками.

Процесс разработки

Сначала была определена структура проекта, после чего в одной папке были созданы HTML-файлы и каталог images. Код редактировался в IntelliJ IDEA, а результат проверялся в браузере. Для сохранения файла использовалось сочетание клавиш Ctrl + S, а для обновления страницы в браузере — Ctrl + R.

Основные этапы

  1. Создать структуру каждого HTML-документа.
  2. Добавить семантические элементы и навигацию.
  3. Заполнить страницы реальной информацией о клубе.
  4. Добавить собственные фотографии в папку изображений.
  5. Проверить ссылки и HTML-разметку.

Пример HTML-разметки

Следующий пример показывает семантический элемент section, применённый в проекте: 

<section>
    <h2>Адрес и контакты</h2>
    <p>Клуб работает круглосуточно.</p>
</section>

Результат проверки: Document checking completed. No errors found.

Почему использована семантика

Вместо одинаковых блоков div для основных частей были выбраны header, nav, main, section и footer. Эти элементы объясняют назначение содержимого браузеру и делают исходный код понятнее. Семантическая структура также помогает пользователям программ экранного чтения.
